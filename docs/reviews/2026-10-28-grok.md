## 2. Ranked findings

`#print axioms` is only a script in `checks/Audit.lean`. No axiom output was regenerated here. The plan’s recorded foundations (`propext`, `Classical.choice`, `Quot.sound` on the dual bridge) were not rechecked.

### F2 — Demonstrated packet defect; low for Theorem 1

Pasted `irreducible` returns false when `modulus < 3`, so it rejects `p = X` (integer 2). The manuscript test accepts it: for degree 1, `⌊s/2⌋ = 0`, there is no gcd check, and `X^2 ≡ X (mod X)`. Hand expansion of the same loop without that guard returns true (`remainder(2,2) = 0`, then `0 = 0`). `F_2[X]/(X) ≅ F_2`, and `det + det = 0`, so a nonzero-`c` certificate for the zero tensor at `n = R = 3` is algebraically valid. `verify` misses `ArithmeticError`, but the `p = X` rejection is a caught `ValueError`, hence a false `False`, not a crash.

`tests/check_review_edge_cases.py` (working tree, not in the paste) asserts `irreducible(2)`, `verify` of modulus 2, and rejection of `0,1,4,5,6`. Against the pasted guard those assertions fail. Against on-disk `modulus < 2` they are consistent with this hand trace. Either way, `s ≥ 5` forces a monic modulus at least `2^s ≥ 32`, so good-trial completeness for Theorem 1 does not use this guard.

### F3 — Clarification, load-bearing, not an in-promise error

Uniqueness of the compatible coefficient uses `dim U ≤ R < n`. The promise gives `n = 3s ≥ 6R+15`. If `R = n`, the trace-determinant form can equal an exterior form. Over `F_2`, `det + det = 0` with `c ≠ 0` and full support. `solve` returns one reduced witness and sets unused columns to zero. A `c = 0` witness is then rejected even if another witness has `c ≠ 0`. Inside the promise the planted transport gives a nonzero `c' = σ^{-1}(c det B)` and the mode-image argument makes it the only solution, so the witness is safe. Dropping `R < n` in Lean would break completeness.

### F4 — Probability attacks that did not land

These were checked as inequalities, not as executable tests.

- Char 2 collapses permutation signs to `+1`. The six-term `det` still vanishes on repeated columns because paired terms sum to zero. It matches both `Field.det` and the test reference expansion.
- Three contractions give `A1* = A2`, `A1* = A3`, `A2* = A3`, hence one self-adjoint block. The fourth weights force commutation with `M_a, M_b, M_d`. One algebra generator forces scalars. Scalars satisfy all four balance equations.
- `v ∈ U_*^⊥` kills every contraction of `E`, so a clean quadruple sees `C_0`. The packet never isolates this sentence; the sampling section depends on it.
- Basis failure is at most `(1+q+q^2)/|A|` because forbidden `K`-flats meet `A` in at most `1`, `q`, and `q^2` points. Generator failure uses fibers of size at most `q^2`, so field coordinates need not be uniform on `A`.
- `β < 5/16` and `γ > 23/32` at `s ≥ 2R+5`, so `(1-β)γ > 1/8`. The written `β < 1/2` and `γ ≥ 1/4` already give a strict product above `2^{-3}`. Then `N · 2^{-4R-3} = h` and `(1-2^{-m})^{h 2^m} ≤ e^{-h} ≤ 2^{-h}`.
- `t = 0` is a non-generator for `s ≥ 2`, and the translate union bound does not assume independence of generation and position. `T*` is multiplication by `t` under `Tr(∑ a_i x_i)`.
- `W(D_T E) ⊆ W(E)` always. The reverse uses joint surjectivity of `x ↦ (u(x), u(Tx))`. Independence for `U_*` passes to any subspace, and the lemma applies to `U_*` directly.
- Early acceptance of another verified representation only lowers failure probability. Eager draws of `4n+s` bits match the prose cap, including rejected trials.
- The finite checker, if it implements the identity, gives soundness without the promise. Uniqueness is not claimed. Failure is not a non-existence certificate.

`check_recovery.py` checks `β < 1/2` and `γ ≥ 1/4` for 200 pairs `R < 25`, `2R+5 ≤ s < 2R+13`. It does not check the product `≥ 1/8`. That is a finite-evidence gap. The analytic step above covers it. Those tests were not run.

The `s = 3, R = 3` one-line failure is outside the promise. Three covectors spanning one dual `K`-line make `A` a `K`-plane, so no clean triple is a `K`-basis. The artifact’s counts were not replayed. The geometry explains exhaustion of that tape. It is not evidence that no other representation exists.

### F5 — Cost claim: no exceeded term found; model not pinned in the archive

The dominant sketches are consistent with a bit-RAM envelope: balance elimination `O(n^6)`, coefficient elimination `O(n^9)`, immutable exterior construction `O(n^9)` from copying `O(n^3)`-bit integers, trace-determinant columns `O(n^7)`. Soft-`O(n^{12})` time and soft-`O(n^8)` live space have slack over `O(n^6)` live bits if candidates are discarded and the length-`L` tape is not stored. No term was derived that exceeds that envelope in this model.

The archived Section 6 does not say RAM versus a single-tape Turing machine. A naive tape simulation can multiply time by a space polynomial and can break `n^{12}`. `docs/resource-model-clarification.md` says the intended model is bit-cost RAM, that a single-tape simulation is not claimed, and that this note is post-archive. That is a specification gap, not a computed counterexample.

Python object overhead and “interpreter overhead” remain unproved slack. The plan is right to refuse them as hypotheses.

### F6 — Low, unverified reachability

`Field.trace` raises `ArithmeticError` if the orbit sum is not in `{0,1}`. `verify` does not catch it. For a correct irreducible modulus the absolute trace lands in `F_2`, so this should be unreachable. It was not executed. A bad multiply would abort a trial instead of returning explicit failure.

The self-adjoint count `s(s+1)/2` is a side remark. Symmetric matrices still have that many parameters in char 2, and this pairing is non-alternating because `x ↦ μx^2` is bijective and trace is surjective. It is not used in the probability theorem.

The M0–M7 order, frozen v0.1.0 target, separation of Python refinement, and refusal to replace `s ≥ 7R+5` in the broader application should stand. The packet contains no proof of that application.

- Treat transport as its own theorem: `g(Tv) = X g(v)`, `f = B ∘ σ ∘ g`, Frobenius commutes with `σ`, `c' ≠ 0`, and the planted form lies in the constructed columns before any solver runs.
- Prove every reduced witness has that same nonzero `c` when `dim U < n`. Keep the `R = n` cancellation as a negative regression outside the promise.
- Define the sample space as `N` eager blocks of `4n+s` bits. Prove `γ` uniformly for every ordered basis of the scalar space, with the scalar independent of the quadruple.

- Leave the three-contraction dimension remark out of the certified theorem.
- Specify irreducibility as the manuscript squaring test, including `p = X`. Do not copy a `modulus < 3` guard into Lean. Fixing pasted Python is optional source refinement, not S006.
